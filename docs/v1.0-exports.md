# v1.0 public-export inventory

Snapshot of every symbol consumers can import from `@questi0nm4rk/hook-kit`, with the v1.0 stability tier per the three-tier system in [`STABILITY.md`](../STABILITY.md).

This file is the source of truth for TASK-001 through TASK-004 (the JSDoc tagging tasks) and feeds TASK-007 (the CI diff check). Update this file in the same commit any time `src/index.ts` or the `./testing` subpath exports change.

## Subpath exports (from `package.json`)

```text
.                     →  src/index.ts            (STABLE — the main barrel)
./engine              →  src/engine/index.ts     (STABLE — engine entry points)
./wrapper/hk          →  src/wrapper/hk.ts       (STABLE — runShell)
./adapters/claude-code → src/adapters/claude-code.ts (STABLE — cc-tools adapter)
./adapters/raw        →  src/adapters/raw.ts     (STABLE — library/test adapter)
./state               →  src/state/types.ts      (STABLE — StateStore interface)
./state/tmpdir        →  src/state/tmpdir-store.ts (STABLE — TmpdirStore)
./state/memory        →  src/state/memory-store.ts (STABLE — MemoryStore)
./testing             →  src/testing/index.ts    (STABLE — testing SDK)
./escalation          →  src/escalation/index.ts (MIXED — envelope schema + PROTOCOL_VERSION STABLE; broker / listener / forwarder primitives INTERNAL)
```

The `./escalation` subpath is mixed-tier: the askpass envelope schema and `PROTOCOL_VERSION` are STABLE (see the per-symbol tier in the subpath table below and `docs/ESCALATION.md`); the broker / listener / forwarder primitives are INTERNAL for v1.0 — exported so worked-example and downstream listeners can use them, but their shape may change in a future minor.

## EXPERIMENTAL exports

The security-uncertainty path (issue #14, SA-01..SA-10) is the first EXPERIMENTAL surface. Every symbol below is tagged `@experimental @since 0.9.0` at its declaration site and is re-exported from `src/index.ts` (the main barrel). Per [`STABILITY.md`](../STABILITY.md), EXPERIMENTAL exports may take a breaking change in any 1.x minor with a one-minor deprecation cycle (not the one-major cycle STABLE gets). ## INTERNAL — file-header `@internal` tag only (no consumer-facing exports)

These files (or specific exports within them) are tagged `@internal` at the file level. They may be imported by source files inside this package but carry NO stability promise — they can move, rename, or be removed in any release including patches.

| Path | Reason |
|---|---|
| `src/engine/helpers.ts` | Engine plumbing — flag aliases, inline-shell extraction. Not re-exported from any public barrel. |
| `src/engine/trace.ts` | Engine verbose-trace plumbing. Not re-exported. |
| `src/escalation/broker.ts` | Reference implementation of the broker socket protocol (the protocol itself is STABLE; the impl is not). |
| `src/escalation/listeners.ts` | Reference implementation of the listener-marker walk. |
| `src/escalation/watch-tui.ts` | Reference TUI listener. |
| `src/escalation/enrich-git.ts` | Opt-in git enrichment for ask envelopes. |
| `src/escalation/forward.ts` | `escalate-up` forwarder. |
| `src/build/cli.ts` | CLI entry — the CLI surface is shipped, but the impl module structure may refactor. |
| `src/build/bundle.ts` | Bundler internals. |

The `src/escalation/askpass.ts` and `src/escalation/envelope.ts` files are NOT marked internal: the envelope schema and the askpass contract are spec'd as STABLE in M1.4. The runtime implementations of those files may still change, but the JSON schema + askpass argv/stdin/stdout contract are locked.

## Verification

`grep -E "^export" src/index.ts` returns 22 lines. Combined with the multi-line `export { ... }` blocks for annotations, errors, types, engine, and the security-uncertainty path, this expands to the 64 distinct symbols in the `src/index.ts` table above (54 STABLE + the 10 EXPERIMENTAL security-uncertainty symbols). Each is represented in this file. `scripts/check-stable-exports.ts` parses the same 64 from `src/index.ts` and is the CI guard that fails on undeclared STABLE removals.
